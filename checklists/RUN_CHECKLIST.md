# Run checklist

- [ ] Goal and excluded scope are explicit.
- [ ] Workspace state and user changes were inspected.
- [ ] Permissions are least privilege and production is false by default.
- [ ] Task DAG has owners, dependencies, sensors and rollback.
- [ ] Stop and escalation conditions are falsifiable.
- [ ] Evidence is attached before state becomes done.
- [ ] Independent verification is used when risk requires it.
- [ ] Release is separate and approval-gated.
- [ ] Handoff exists only at a real continuity boundary.
- [ ] Harness improvement candidates have regression evidence.
